# Product

This is a React learning project from the Udemy course "React: De cero a experto" (Section 9 - Profundizando Hooks). It is a hands-on demo app (`04-hooks-app`) that explores React hooks through progressively complex examples.

## Purpose

Each subfolder under `src/` is a self-contained lesson demonstrating a specific hook or pattern:
- `01-useState` — basic state management
- `02-useEffect` — side effects and lifecycle
- `03-examples` — composing multiple custom hooks (Pokémon API example)
- `04-useRef` — DOM refs without re-renders

The active component rendered in `main.tsx` is swapped by commenting/uncommenting imports as lessons progress.
